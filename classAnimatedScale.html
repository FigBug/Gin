Detailed Description

An Animated<float> scale applied to its owner with juce::Component::setTransform, about an origin relative to the owner's bounds (its centre by default), so it zooms from the centre instead of towards the bottom right.

The pivot follows the owner when it moves or resizes, also during a "bounds" transition. A scale of 1 clears the transform.

It owns the owner's transform: a transform set elsewhere is replaced on the next change. A component that needs its own transform too should be scaled through a parent or child. Hit testing follows the transform; JUCE repaints the enlarged area. Decorations painted by an ancestor (shadows) can follow it through a juce::ComponentListener on the owner: setTransform sends componentMovedOrResized (c, false, false).

The layout's "scale" entry uses it as well (with "origin"); give a component a scale from the layout or from code, not both.

// layout json: { "id": "tile", "transition": { "scale": "60 inOutQuad" } }
class Tile : public juce::Button
{
public:
void buttonStateChanged() override { zoom.setTarget (isOver() ? 1.03f : 1.0f); }
private:
gin::AnimatedScale zoom { *this };
};
