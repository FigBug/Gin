Detailed Description

Ticks all running Animated and Crossfade values on the vertical blank of the window they show in.

Holds a juce::VBlankAttachment per window only while something in it animates, so it costs nothing when idle. Shared through a juce::SharedResourcePointer; used internally, there is no need to touch it.
