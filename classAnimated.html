Detailed Description

template<typename T>
class Animated< T >

A value that eases to a new target over a Transition and repaints its owner on every step.

  • Setting a target starts from the current value, so retargeting mid-flight continues smoothly; setting the target it already heads for changes nothing.
  • Reading it (get() or the implicit conversion) returns the current value, so paint() just reads it.
  • A target set while the owner isn't showing, with an instant transition, or before a layout defined any transition, applies at once (setValue()).
  • Steps run on the vertical blank of the owner's window via a shared AnimationDriver, which goes idle when nothing animates.

The transition comes from the layout json by the property name given to the constructor (see Transition for the json syntax and inheritance), or from a preset name or inline spec passed to setTarget().

Any type with an Interpolator works: float (any scalar such as a font height or corner radius), double, juce::Colour, juce::Point<float>, juce::Rectangle<float>, juce::Rectangle<int>, juce::Font and juce::ColourGradient come with one.

// layout json: "transitions": { "quick": "100 outQuad" },
// { "id": "panel", "transition": { "glow": "quick" } }
class Panel : public juce::Component
{
public:
void setLit (bool lit)
{
glow.setTarget (lit ? 1.0f : 0.0f); // the layout's "glow" transition
tint.setTarget (lit ? juce::Colours::gold : juce::Colours::grey, "250 inOutQuad");
}
void paint (juce::Graphics& g) override
{
g.setColour (tint.get().withMultipliedAlpha (glow));
g.fillEllipse (getLocalBounds().toFloat());
}
private:
gin::Animated<float> glow { *this, "glow" };
gin::Animated<juce::Colour> tint { *this, "tint", juce::Colours::grey };
};

template<typename T>
void Animated< T >::updateTarget ( T newTarget)

Changes the target of a running transition without restarting it: start value, start time and easing stay, so it still ends on time.

For a target that moves continuously while a transition runs, e.g. a level dragged during a colour blend. Without a running transition it jumps (setValue()).

template<typename T>
void Animated< T >::followTarget ( T newTarget)

For a target that streams in, like live colours or a meter: starts a transition when none runs, otherwise moves the running one's target (updateTarget()).

The value keeps following without restarting on every update, and without lagging further behind than one transition.
