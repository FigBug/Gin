Detailed Description

An image and an ImageFilter version of it, blended by an Animated<float> amount: 0 shows the image, 1 the filtered one, e.g.

a contrast boost while hovered. Only what is drawn through draw() is filtered, never the owner's other painting or its children.

The filter is applied once to the full size image and a second MipMap built from the result; that happens again only when the image or the filter changes, so painting at any size or scale (HiDPI) costs two MipMap::draw calls at most (see drawBlend).

The amount's transition comes from the layout like any Animated's ("imageFilter" by default). The owner's "states" (see States) drive it: a state with an "imageFilter" spec sets the filter and eases the amount to 1 while it is active, back to 0 after:

// layout json: { "id": "cover", "states": { "hover": { "imageFilter": "contrast 30 saturation 120" } },
// "transition": { "imageFilter": "150 outQuad" } }
class Cover : public juce::Component
{
public:
Cover() { image.setImage (gin::MipMap (loadCover())); }
void paint (juce::Graphics& g) override { image.draw (g, getLocalBounds().toFloat()); }
private:
gin::AnimatedImageFilter image { *this };
};

Without states, set the filter and drive amount yourself.
