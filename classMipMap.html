Detailed Description

An image with its halved levels down to 16 px, each halving a rounded 2x2 box average, so drawing it smaller picks the nearest larger level and stays sharp without aliasing.

draw() picks the level for the physical pixel size (HiDPI included) and draws it with low resampling quality when the level matches the size exactly, high otherwise.

Copies are cheap: the levels are juce::Image objects, which share their pixels.

gin::MipMap cover { juce::ImageFileFormat::loadFrom (file) };
void paint (juce::Graphics& g) override
{
cover.draw (g, getLocalBounds().toFloat(), juce::RectanglePlacement::centred);
}
