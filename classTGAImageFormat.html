Detailed Description

Support for reading and writing Truevision TGA files.

Reads colour mapped, true colour and greyscale images, each either uncompressed or run length encoded, at 8, 15, 16, 24 or 32 bits per pixel, with the rows and columns running whichever way the image descriptor says.

Always writes 32 bit uncompressed true colour images.

A TGA has no magic number at the front, so canUnderstand() looks for the file footer that version 2 of the format puts at the end, and failing that satisfies itself that the header makes sense. Give it a stream it can seek.
