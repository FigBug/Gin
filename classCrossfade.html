Detailed Description

template<typename T>
class Crossfade< T >

A discrete value that can't blend, like a text or an icon: on a change the previous value fades out while the new one fades in, over a Transition found exactly like Animated's (layout "transition" by property name, preset, inline spec).

Painting draws getPrevious() at an opacity of 1 - getProgress() and getCurrent() at getProgress(), or uses the drawText / drawIcon helpers which do just that. T needs copy assignment and operator==; juce::String and juce::Path are the usual ones.

A new target while a fade runs restarts it from 0, with the value that showed more so far as the one fading out. updateTarget() changes the incoming value without a restart.

// layout json: { "id": "status", "transition": { "caption": "150 inOutQuad" } }
class Status : public juce::Component
{
public:
void setOnline (bool online) { caption.setTarget (online ? "Online" : "Offline"); }
void paint (juce::Graphics& g) override
{
gin::drawText (g, caption, getLocalBounds().toFloat(), juce::Font (juce::FontOptions (15.0f)),
juce::Colours::white, juce::Justification::centred);
}
private:
gin::Crossfade<juce::String> caption { *this, "caption", "Offline" };
};

Paints both sides of the fade with your own drawing: calls paintOne (value, opacity) for the previous value at 1 - progress and the current one at progress, skipping a side at opacity 0.

Multiply your colours' alpha by the opacity.

weight.draw ([&] (int w, float opacity)
{
g.setColour (juce::Colours::white.withMultipliedAlpha (opacity));
g.setFont (juce::FontOptions (14.0f).withStyle (w > 500 ? "Bold" : "Regular"));
g.drawText (label, area, juce::Justification::centred);
