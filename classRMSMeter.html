Detailed Description

Sliding window RMS meter, one reading per channel.

The window length is fixed at prepare() time. Readings are plain RMS, so a full scale sine reads -3.01 dBFS; add 3.01 dB for an AES-17 style scale where a full scale sine reads 0.

Call process() from the audio thread; the getters are safe from any thread.
