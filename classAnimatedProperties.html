Detailed Description

The animated values of one component that the layout and its States share, so a base value (the layout's "alpha" and "scale" entries) and a state's value (e.g.

a hover scale) drive the same animation instead of fighting over it. A state's value wins while the state is active; leaving it eases back to the base value. Values:

  • "alpha" (Component::setAlpha, 0 hides, see LayoutSupport), base 1 without an entry
  • "scale" (an AnimatedScale about the "origin"), base 1 without an entry
  • "imageFilter" (a spec, see ImageFilter): sets the filter of every AnimatedImageFilter the component owns and eases their amount to 1, to 0 when no state sets one
  • "boxShadow" (see BoxShadow), base none without an entry

Timings come from Transition::forProperty for "alpha", "scale" and the filters' own property names ("imageFilter" by default). Kept in the component's properties, it lives as long as the component. Created on demand; LayoutSupport, States and AnimatedImageFilter use it, code rarely needs to.
