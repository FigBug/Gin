Detailed Description

The non-template part of Animated and Crossfade: the owner, the property name, the running transition and the registration with the shared AnimationDriver.

◆ onChange

std::function<void()> AnimatedBase::onChange

Called on every change of the current value (each animation step, and jumps), after the owner was asked to repaint.

Use it for anything beyond a repaint, e.g. moving child components. When a transition ends, isAnimating() is already false here.
