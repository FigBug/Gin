◆ moveRealCursor

bool RemoteServer::Options::moveRealCursor = true

Move the real cursor to the point being clicked.

JUCE reports the OS cursor position for MouseInputSource::getScreenPosition(), so code that asks what is under the mouse only agrees with injected events if the cursor is actually there. Costs you your cursor while a client drives the UI.
